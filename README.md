# SmartPong
An IoT wearable and data analytics platform dedicated to objective, in-depth throw analysis. Features on-device and serverside processing to capture, reconstruct, and evaluate throwing biomechanics.

## Project Structure

- `firmware/`: ESP32 source code. Deployed to the M5 watch. It handles data capture and on-device machine learning for rapid throw detection.
- `classification/`: Jupyter notebooks detailing the data science pipeline (feature extraction, decision tree generation, and metric exploration).
- `backend/`: FastAPI application that acts as the server-side processor. It receives detected throws via MQTT, computes detailed metrics (acceleration, drift, trajectory), and stores personalized user profiles.
- `frontend/`: Vue.js application that provides a dashboard for visualizing throw metrics, user profiles, and settings.

## Getting Started

### Starting the Application (Backend, Frontend, and Database)

The backend, frontend, and MongoDB database are containerized and can be started together using Docker Compose.

1. Ensure Docker and Docker Compose are installed on your system.
2. From the root directory of the project, run:
   ```bash
   docker compose up --build
   ```
   *Add the `-d` flag to run the containers in the background.*

3. The frontend will be accessible at `http://localhost:5173`.
4. The backend API will be accessible at `http://localhost:8000`.
5. The MongoDB database will be running on `localhost:27017`.

### Firmware Configuration (Wi-Fi)

To flash the M5 watch, you must first configure the Wi-Fi credentials so the ESP32 can connect to your local network and communicate with the MQTT broker/backend.

The `sdkconfig` file, which stores these settings, is **not shared via git** (it is excluded in `.gitignore`). It will be **autogenerated** upon your first build or configuration run, but you must manually set your network details.

1. Navigate to the `firmware/` directory:
   ```bash
   cd firmware
   ```
2. Open the ESP-IDF configuration menu:
   ```bash
   idf.py menuconfig
   ```
3. Navigate to **Example Connection Configuration**.
4. Set your **WiFi SSID** and **WiFi Password**.
5. Save and exit the menu. This will generate or update your `sdkconfig` file.
6. Build and flash the firmware to your device:
   ```bash
   idf.py build flash monitor
   ```

*(Alternatively, if you already have an autogenerated `sdkconfig` file, you can open it manually and edit the `CONFIG_EXAMPLE_WIFI_SSID` and `CONFIG_EXAMPLE_WIFI_PASSWORD` properties.)*
